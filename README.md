# Code2Chill – Official Club Website

### Where Ideas Turn Into Code

Code2Chill is a student-focused coding club website designed to bring developers together, encourage collaboration, showcase events, and create a community of learners.

## Features

- Modern and responsive homepage
- About Code2Chill section
- Events showcase
- Our Team section
- Gallery section
- Join the Club section
- Contact information
- Responsive navigation

## Tech Stack

- React.js
- Vite
- CSS
- React Router

## Getting Started

1. Clone the repository.
2. Open the frontend folder.
3. Install dependencies.
4. Start the development server.

```bash
cd frontend
npm install
npm run dev
```
